# Instagram Grid Studio

Create a website that is optimized both for mobile and computer use and should be like one of those instagram arranging apps where you can see your instagram page EXACTLY how it looks in instagram, not something similar, but exact. The the user must be able to upload, delete, rearrange photos, reels, story highlights, pinned, etc in the grid and it must look like a 1-1 copy of their instagram. 

Okay. So for now, the back end should be simplistic. So no login for now, just as is. But keep in mind that login will be there in the future. So for now, we simply have a situation where the user does not connect his Instagram account and is simply able to upload the photos, drag and drop them, move them around, et cetera. So it looks exactly like Instagram, but for now without the complex back end. But there still should obviously be a back end so that the user has everything saved. 

For the moment, this is used as a private instrument for simply myself, so we don't need to have multiple accounts, et cetera. But I should be able to create multiple grids
